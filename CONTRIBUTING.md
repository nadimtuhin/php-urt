# Contributing to php-urt

Thank you for your interest in contributing!

## Getting Started

1. Fork the repository
2. Clone your fork: `git clone https://github.com/YOUR_USERNAME/php-urt.git`
3. Install dependencies: `composer install`
4. Copy `.env.example` to `.env` and configure your URT server details
5. Create a feature branch: `git checkout -b my-feature`

## Making Changes

- Keep changes focused and minimal
- Follow existing code style (PSR-12 where applicable)
- Add or update documentation if behaviour changes

## Submitting a Pull Request

1. Push your branch to your fork
2. Open a Pull Request against `main`
3. Describe what you changed and why
4. Link any related issues with `Fixes #N`

## Reporting Issues

Use the [GitHub Issues](https://github.com/nadimtuhin/php-urt/issues) tab. Include:
- PHP version
- Steps to reproduce
- Expected vs actual behaviour
